# OpenSource

OpenSource is a simple platform for viewing, creating, and managing website source code.

## Features

- 🔐 Login & Signup
- 📁 Create source-code projects
- 💻 Edit website source code
- 📦 Import ZIP files
- 🗜️ Export projects as ZIP
- ⚙️ Project configuration
- 🚀 Vercel deployment support

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Development

```bash
npm install
npm run dev
